<Callout type="warning">
	**Deprecated - JSON RPC Only**: This legacy version of `@haneullabs/dapp-kit` only works with the
	deprecated JSON RPC API and will not be updated to support gRPC or GraphQL. For new projects, use
	[`@haneullabs/dapp-kit-core` and `@haneullabs/dapp-kit-react`](/dapp-kit).
</Callout>

The Haneul dApp Kit is a set of React components, hooks, and utilities to help you build an app for the
Haneul ecosystem. Its hooks and components provide an interface for querying data from the Haneul network
and connecting to Haneul wallets.

### Core features

Some of the core features of the dApp Kit include:

- Query hooks to get the information your app needs
- Automatic wallet state management
- Support for all Haneul wallets
- Pre-built React components
- Lower level hooks for custom components

## Install

To use the Haneul dApp Kit in your project, run the following command in your project root:

```npm
npm i --save @haneullabs/dapp-kit @haneullabs/haneul @tanstack/react-query
```

## Setting up providers

To use the hooks and components in the dApp Kit, wrap your app with the providers shown in the
following example. The props available on the providers are covered in more detail in their
respective pages.

```tsx
import { createNetworkConfig, HaneulClientProvider, WalletProvider } from '@haneullabs/dapp-kit';
import { getFullnodeUrl } from '@haneullabs/haneul/client';
import { QueryClient, QueryClientProvider } from '@tanstack/react-query';

// Config options for the networks you want to connect to
const { networkConfig } = createNetworkConfig({
	localnet: { url: getFullnodeUrl('localnet') },
	mainnet: { url: getFullnodeUrl('mainnet') },
});
const queryClient = new QueryClient();

function App() {
	return (
		<QueryClientProvider client={queryClient}>
			<HaneulClientProvider networks={networkConfig} defaultNetwork="localnet">
				<WalletProvider>
					<YourApp />
				</WalletProvider>
			</HaneulClientProvider>
		</QueryClientProvider>
	);
}
```

## Using UI components to connect to a wallet

The dApp Kit provides a set of flexible UI components that you can use to connect and manage wallet
accounts from your app. The components are built on top of
[Radix UI](https://www.radix-ui.com/primitives) and are customizable.

To use the provided UI components, import the dApp Kit CSS stylesheet into your app. For more
information regarding customization options, check out the respective documentation pages for the
components and [themes](/dapp-kit/legacy/themes).

```tsx
import '@haneullabs/dapp-kit/dist/index.css';
```

## Using hooks to make RPC calls

The dApp Kit provides a set of hooks for making RPC calls to the Haneul blockchain. The hooks are thin
wrappers around `useQuery` from `@tanstack/react-query`. For more comprehensive documentation on how
to use these query hooks, check out the
[react-query documentation](https://tanstack.com/query/latest/docs/react/overview).

```tsx
import { useHaneulClientQuery } from '@haneullabs/dapp-kit';

function MyComponent() {
	const { data, isPending, error, refetch } = useHaneulClientQuery('getOwnedObjects', {
		owner: '0x123',
	});

	if (isPending) {
		return <div>Loading...</div>;
	}

	return <pre>{JSON.stringify(data, null, 2)}</pre>;
}
```
