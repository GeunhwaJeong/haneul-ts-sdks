Kiosk SDK is a tool to interact with Haneul and Haneullabs Kiosk. You can use it to query kiosk related
data, build transactions to interact, and extend Kiosk to support custom rules.

## Installation

```npm
npm i @haneullabs/kiosk
```

## About

The Kiosk SDK exports a client extension that integrates with Haneul clients. Add it to your client
using `$extend(kiosk())` to access kiosk functionality through `client.kiosk`.

> The Kiosk SDK requires `HaneulJsonRpcClient` or `HaneulGraphQLClient`. It does not work with
> `HaneulGrpcClient` because it uses event queries that are not available in gRPC.

- [Read more about setting up the Kiosk client extension](/kiosk/kiosk-client/introduction)
